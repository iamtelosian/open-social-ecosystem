# Open Social Ecosystem

Working paper for an open social ecosystem: social applications on shared open protocols, where identity, graph, and ranking are portable and leaving an app does not mean leaving your friends.

Everything here is a draft under active attack. Easy agreement is worth nothing - the strongest contribution is a named objection.

## Contents
- `whitepaper/SKELETON.md` - the current argument map: architecture, conformance framework, economics, bootstrapping, objection register
- `whitepaper/ch01-problem.md` - Chapter 1 draft: the problem
- `research/protocol-verification.md` - verified protocol evidence with sources (ATProto, ActivityPub/FEP-7628, ODRL, x402, L402, Szabo/Shirky)
